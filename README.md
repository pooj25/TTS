# Track Tech Solution

Good morning sir, I developed **Track Tech Solution**, a dynamic digital intelligence web platform for apparel and textile manufacturing operations built with Laravel 12, PHP 8.2, Blade, Tailwind CSS and SQLite. 

The application features an interactive Three.js WebGL 3D engine allowing users to rotate real-time 3D factory models, an Alpine.js ROI calculator for dynamic cost-savings estimation and a continuous partner logo marquee displaying 9 industry leaders. 

Demo booking and contact forms are connected to the SQLite database via Laravel Eloquent ORM, and the entire application is containerized with Docker (Nginx + PHP-FPM), version-controlled on GitHub and deployed on Render with 24/7 uptime monitoring.
